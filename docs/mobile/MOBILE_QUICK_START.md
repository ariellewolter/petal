# Petal Mobile - Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Start Server
```bash
cd /path/to/task_tracker_app
npx serve .
```

### Step 2: Get URL
Note the URL shown (e.g., `http://192.168.1.100:3000`)

### Step 3: Open on iPad/iPhone
1. Open Safari
2. Go to the URL
3. Tap Share (□↑) → "Add to Home Screen"
4. Tap "Add"

### Step 4: Launch
Tap the Petal icon on your Home Screen!

---

## ✅ What Works

- ✅ All features (tasks, projects, files, calendar)
- ✅ Touch gestures (swipe sidebar, dismiss modals)
- ✅ Offline mode (cached assets)
- ✅ Portrait & landscape
- ✅ Data storage (localStorage)

## ⚠️ Limitations

- ⚠️ File links need share URLs (OneDrive, iCloud)
- ⚠️ No local file access (iOS limitation)
- ⚠️ Data stored per-device (use Export/Import to sync)

---

## 📱 Mobile Features

### Gestures
- **Swipe left** on sidebar → Close
- **Swipe right** from edge → Open sidebar
- **Swipe down** on modal → Dismiss
- **Tap hamburger** (☰) → Toggle sidebar

### Touch Targets
- All buttons: 44px+ (iOS compliant)
- Form inputs: 48px height
- Easy to tap on mobile

---

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Won't install | Use Safari, ensure HTTPS/localhost |
| Blank screen | Check server is running, verify URL |
| Data not saving | Check localStorage enabled, not Private mode |
| Sidebar stuck | Refresh page, check console |
